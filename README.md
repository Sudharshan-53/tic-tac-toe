# Tic Tac Toe in C

A simple two-player Tic Tac Toe game implemented in C with input validation, turn-based moves, and win/draw detection.

## Description

This program allows two players to play Tic Tac Toe on a 3x3 board in the terminal. Players alternate turns by entering row and column numbers to place their marks (X and O). The game checks for valid moves, detects a winner or draw, and displays the game board after each turn.

## Features

- 3x3 game board displayed in terminal
- Validates user input for moves
- Detects win conditions (rows, columns, diagonals)
- Detects draw when all board spaces are filled
- Player turn alternation between 'X' and 'O'
